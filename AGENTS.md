## App Skills

This app has skill packages selected in its Settings tab, vendored at `.codex/skills/<name>/SKILL.md`
(Codex additionally discovers the same set natively via `.agents/skills/`; Claude Code via `.claude/skills/`).
Read the vendored copy directly before implementing something one of these covers. Re-vendored
automatically by Studio before every run.
- `expenseflow` — Use this skill to manage end-to-end expense and reimbursement workflows. The AI can submit and validate expenses, process receipts, determine approval routes based on configured spending rules, enforce budget limits and self-approval restrictions, manage approvals and rejections, and track expense status while respecting organization-specific policies, permissions, localization, and fiscal rules.
